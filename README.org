* genomic-refgen

#+begin_src lisp
  (setf *a-parameter* "a-value")
  ;; set all
  (deploy-refgen)
#+end_src

will download, decompress, concatenate, process to reduced representation, index all chromosomes

in the *target-dir* you will have
- concatenated and individual chromosomes
- all as srg and non srg
- all indexed
